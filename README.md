# HANUMAN ELECTRICALS

A responsive solar solutions website for HANUMAN ELECTRICALS in Siddhartha Nagar, Mothi Umari, Akola, Maharashtra. Built with semantic HTML, custom CSS and vanilla JavaScript, with no build step or framework dependencies.

## Run locally

From this directory, run:

```powershell
python -m http.server 5173
```

Then open [http://localhost:5173](http://localhost:5173).

## What's included

- Responsive navigation and layouts for phones, tablets and desktop
- Instant English/Marathi language switch with a shared translation catalog in `translations.js`
- Bilingual government solar subsidy offer with scheme eligibility disclaimer and management credits
- Home, business and industrial solar solution sections
- Coordinate-positioned, interactive Vidarbha service map centered on Akola
- Filterable illustrative project profiles with accessible detail dialogs
- Founder profiles and a clearly marked testimonial placeholder
- Indicative rooftop solar estimate calculator
- Validated enquiry form with explicit preview-only submission status
- Local SVG image fallbacks for remote photo failures

## Before publishing

- Replace the illustrative project profiles and stock photography with approved company work and imagery.
- Replace founder portrait placeholders and the testimonial placeholder with approved assets and customer-approved content.
- Connect the enquiry form to a real, monitored inbox or form-processing service. It does not send data in this preview.
- Review the Marathi copy with a local language editor before publishing.
- Confirm the complete business/WhatsApp contact number before publishing. The supplied number is intentionally shown as `738587xxxx`; WhatsApp calls-to-action currently direct visitors to the contact form rather than inventing a number.
- Review the illustrative map coordinates and qualitative density labels before publishing; they indicate service focus, not completed project counts.
- Verify the calculator assumptions against current local tariffs, system pricing, site conditions and applicable incentives.
- Confirm the applicable government subsidy scheme and current eligibility rules before publishing or promoting the indicative subsidy offer.
- Add approved company contact details and any required privacy, accessibility and legal information.

Google Fonts and Unsplash photography are loaded remotely. If a remote photo fails, the page falls back to the local `assets/solar-fallback.svg` illustration. System fonts are used if Google Fonts are unavailable.
